# シナモンルーレット ☁️

**できるか、できないか。確率はいつでも 1/2！？**

どんなお題も「できる／できない」の2択で決める、水色×白のふわふわ主人公ルーレットです。
回したあとには、そのお題の**本当の確率**も表示されます。

「100兆個のサイコロを投げて全部1になる確率と、人が壁をすり抜ける確率、どっちが低い？」という話題に
「できるかできないかの2分の1じゃないん？」と答えた、主人公すぎる考え方が元ネタです。

HTML / CSS / JavaScript だけで動きます。サーバーもビルドも不要なので、GitHub Pages にそのまま公開できます。

## あそびかた

1. お題を入力する（またはお題ボタンを押す）
2. 「ルーレットをまわす」
3. 「できる！」か「できない…」が決まり、本当の確率と「主人公は何倍ポジティブか」が表示される

### 2つのモード

| モード | 「できる」になる確率 |
| --- | --- |
| 主人公モード | どんなお題でも **1/2（50%）** |
| 現実モード | お題の**本当の確率**。ルーレットの「できる」ゾーンもその大きさになる（サイコロ100兆個だと見えない） |

自分で入力したお題は本当の確率がわからないため、現実モードでも 1/2 で回ります。

### 用意してあるお題と本当の確率

| お題 | 本当の確率 |
| --- | --- |
| 100兆個のサイコロを投げて全部1になる | (1/6)^(10^14) ≒ 10^−77,815,125,038,364 |
| 人が壁をすり抜ける（量子トンネル効果） | およそ 10^−(9×10^33)（体重60kg・厚さ10cmの壁で超ざっくり計算） |
| 年末ジャンボ宝くじ（1枚）で1等が当たる | 2,000万分の1 |
| ポーカーで最初の5枚がロイヤルストレートフラッシュ | 4 / 2,598,960 ＝ 64万9740分の1 |
| 1回勝負のじゃんけんで10連勝（あいこも負け） | (1/3)^10 ＝ 5万9049分の1 |
| コインを10回投げて全部表 | (1/2)^10 ＝ 1024分の1 |
| サイコロを1回振って1が出る | 1/6 |
| 30人のクラスに誕生日が同じ人がいる | 約70.6%（誕生日のパラドックス。主人公理論の1/2より高い！） |

## そのほかの機能

- **カチカチ音**：回転中に鳴る。結果の「キラキラ」「ぽよよ〜ん」音も、Web Audio API で合成しているので音声ファイルは不要
- **マスコット「くもいぬ」**：結果に合わせて表情が変わる（オリジナルキャラクター）
- **当たりの演出**：「できる！」のときは雲・ハート・星の紙吹雪
- **記録**：回した回数・できる率・最近のお題（20件）を、このブラウザの localStorage（`cinnamonRoulette.v1`）に保存
- **シェア**：結果をシェア、またはコピー
- **表示**：スマホ・PC・ダークモード・動きを減らす設定（prefers-reduced-motion）に対応
- **公平な抽選**：抽選には `crypto.getRandomValues` を使用

## GitHub Pages で公開する

1. リポジトリの **Settings → Pages** を開く
2. Source を **Deploy from a branch** にする
3. Branch で `main` と `/ (root)` を選んで **Save**
4. 1〜2分後に `https://kento20020.github.io/cinnamon-roulette/` で遊べる

## 手元で動かす・テスト

`index.html` をブラウザで開くだけで動きます。

```bash
python3 -m http.server 8000   # → http://localhost:8000/
npm test                      # 抽選の公平さ・針の止まる位置・確率表示のテスト
```

## ファイル構成

```
index.html            画面の骨組み
assets/css/style.css  デザイン（水色×白のふわふわ）
assets/js/logic.js    お題データと計算（抽選・止まる位置・確率の表示）
assets/js/sound.js    効果音（Web Audio API）
assets/js/app.js      ルーレットの描画・回転・結果・記録
tests/logic.test.js   計算のテスト
```

## 注意

- 非公式のオリジナル作品です。特定のキャラクターや企業とは関係ありません。
- 壁すり抜けの確率は、仮定しだいで桁が大きく変わる「ざっくり計算」です。
